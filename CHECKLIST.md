# Manual tests

A record of what was tested by hand and how, besides the [automated tests](README.md#automated-tests) that run on every change: it's there to repeat them when that part is touched. "Real" is with real songs, programs or browsers; "Simulated", forcing the case (an old graphics card, say) without having it.

## Setup

The real tests were run on:

- Windows with WSL2 (Ubuntu 24.04.5)
- AMD Ryzen 5 8500G (6 cores, 12 threads), 11 GB of RAM available in WSL
- NVIDIA GeForce RTX 4060 with 8 GB, driver 610.88
- Python 3.12.3, PyTorch 2.15.0 (CUDA 13.2), audio-separator 0.48.0, Essentia 2.1b6.dev1389, yt-dlp 2026.10.26, Rubber Band 3.3.0, ffmpeg 6.1.1
